# Portfolio — Emiliana Lucia Amaro Andina

Portafolio profesional de desarrolladora frontend junior. Diseño dark startup tech con acento verde-lima eléctrico.

## Estructura del proyecto

```
portfolio/
├── index.html          ← Estructura HTML
├── css/
│   └── styles.css      ← Todos los estilos (design tokens, layout, componentes, responsive)
├── js/
│   └── main.js         ← Interactividad (cursor, nav, reveal, typewriter, skill bars, formulario)
├── assets/
│   └── (imágenes, íconos, favicon)
└── README.md
```

## Stack

- HTML5 semántico + accesibilidad (ARIA)
- CSS3 puro (variables, grid, flexbox, animaciones)
- JavaScript vanilla (IntersectionObserver, requestAnimationFrame)
- Google Fonts: Syne + Outfit

## Uso local

```bash
# Con Live Server (VS Code) o cualquier servidor local:
npx serve .
# o
python3 -m http.server 3000
```

Abrir `http://localhost:3000` en el navegador.

## Assets

Colocar en `/assets/`:
- `foto.jpg` — foto de perfil (usada en hero y about)
- `favicon.ico` — ícono de pestaña
- Cualquier imagen de proyectos
